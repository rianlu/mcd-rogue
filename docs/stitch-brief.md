# 交给 Stitch 的画面说明

只看这一份。一次做一屏，角色单独做一次。不要画经验条，不要画三选一升级。

这是俯视卡通网页游戏。电脑和手机看的是同一间房，房间 960×540，镜头固定，整间房都看得见，镜头不跟着人走。人物在房间里走。

独立作品，不是麦当劳官方产品。不要金拱门，不要 Ronald，不要官方吉祥物，不要 Speedee 字体，不要深色地牢，不要像素风。餐品只出现在技能格和商品卡里，用写实商品照片，不把汉堡画成角色。

## 颜色和字

| 名字 | 色值 | 用在 |
| --- | --- | --- |
| 金 | `#FFBC0D` | 主按钮、选中、法术标签 |
| 红 | `#DB0007` | 生命、价格、危险、法球标签 |
| 白 | `#FFFFFF` | 卡片 |
| 黑 | `#000000` | 金底上的字 |
| 炭黑 | `#2D2D2D` | 白底上的字、描边、肉盾标签 |
| 浅灰 | `#F7F7F7` | 卡片里的次级底 |
| 牛皮纸 | `#B69A81` | 障碍、桌椅、纸袋。不拿来写字 |
| 浅金地面 | `#FFE7A3` | 第一场地面 |

字的搭配：白底写炭黑或红字；红底写白字；金底写黑字。不要金底红字，不要白底金字，不要红底金字。

拉丁字母和数字用 Fredoka，中文用 Noto Sans SC。正文不小于 16px，商品名 20px，价格数字 28px。按钮是胶囊（圆角拉满）。卡片圆角 24px。角色和怪物用炭黑描边 4px。阴影只有一层，金色 20% 透明。

流派色：法球红底白字，法术金底黑字，肉盾炭黑底白字。

## 角色

都要正面、扁平、圆润，缩到大约 28 像素仍能分清是谁。不要写实，不要尖牙和血迹。

**玩家。** 白圆，炭黑描边。头顶一小节红色圆弧，像一撮短发，不是拱门。两个小点做眼睛。受伤时闪一下红，平时不闪。

**游走怪。** 红色圆，会动。眼睛朝玩家。比玩家略小。

**定点怪。** 红色圆角方块，不动。顶上一条短的黑色线，表示它在瞄准。

**精英。** 和对应的普通怪同一外形，放大约 1.3 倍，描边改成金色。

**头目。** 红色胶囊，比精英更大，仍是扁平卡通。炭黑描边。不要另画一只写实动物。

## 两间房

每间房 8 块圆角障碍，中间留出走道。障碍是牛皮纸色，炭黑描边。其中挡人的是实心；只挡子弹的那种，里面再加一圈 2px 白线。

**街角。** 地面浅金 `#FFE7A3`，格子线用金色。障碍像圆角桌和纸袋。

**后厨。** 地面浅灰 `#F7F7F7`，格子线用牛皮纸色。障碍像圆角操作台。同样不要金拱门。

## 地上的东西

| 东西 | 样子 |
| --- | --- |
| 金币 | 金色圆币 |
| 治疗 | 白圆，中间红十字 |
| 护盾 | 白方块，炭黑外框，金色内框 |
| 技能 | 白圆里放一张商品照片，炭黑描边 |

玩家的普攻是细的红色短条。怪物的子弹是炭黑三角。法球是金色圆，圆心可以贴一小张商品图。

## 要画的界面

战斗时下面这 8 格一直都在：空格是虚线；有技能的格子是商品照片，角上一个流派色点，被动在图下 1 到 3 个点，选过分支的主动在图下写「支」。

顶栏从左到右：设置、手册、暂停。右侧是生命（白槽红条）和金币（黑字）。这三个按钮横着排，不要竖着堆在左下角。

### 1. 横屏战斗

房间铺满 16:9。顶栏盖住上沿，高约 56px。底部一条浅色底，上面一行 8 个技能格，每格约 56px。触屏时左下角有轮盘：半透明金环，炭黑钮，直径约 112px。技能格从轮盘右边开始，不和轮盘重叠。鼠标时不画轮盘，8 格在底部居中。

### 2. 竖屏战斗

房间仍是完整的 16:9，放在屏幕中段，按宽度缩放，上下留白。上段是同一条顶栏。下段约 240px：左边轮盘，右边技能两行四格，每格大约 56px 高。拇指不盖住房间里的怪物。

### 3. 技能卡和转转回收

点一格后战斗暂停。白卡片：商品照片、技能名、主动或被动、一两句效果、商品现价（白底红字）、一行「成色一般，转转回收 7.5」。两个胶囊按钮：「确认回收」「再想想」。回收按钮用金底黑字。横屏时卡片从那一格往上长。竖屏时卡片开在房间和底栏之间，不盖住轮盘。

### 4. 商店，横屏

压一层 40% 炭黑。白卡片居中。标题「商店」。6 张商品卡，两行三列。每张卡：流派顶栏、商品照片、名字、一句效果、红色现价、金底黑字的「购买」。买不起的卡变浅，按钮仍能看见。底部仍是那 8 个技能格，每格下有「转转回收」。卡片下沿还有「刷新 20」和「继续」。

### 5. 商店，竖屏

同一张商店。6 张商品卡改成两列三行。8 个技能格在商品卡上面，可以横滑。购买、刷新、继续放在卡片下沿，给拇指点。

### 6. 分支

白卡片，标题是技能名。两张并排的白卡，各写一条分支，下面一个「就这个」按钮。没有第三张。

### 7. 手册

白卡片，可滚动。顶上三个分段：法球、肉盾、法术。选中的分段用对应流派色。列表里每一行是商品小图、名字、主动或被动、一句效果。打开时战斗暂停，底下仍能看见 8 格。

### 8. 设置

小白卡片，左上角附近，不要挡房间中心。标题「设置」。三行开关：音效、背景音乐、受击震动。金底黑字的「关闭」。

### 9. 暂停

房间变暗。中间一个金底黑字的大按钮「继续」，下面两个较小的按钮「手册」「设置」。
