# 设计风格

这份文档约束 `mcd-rogue` 的画面。玩法以 [game-plan.md](./game-plan.md) 为准。交给外部画界面和角色时，用 [stitch-brief.md](./stitch-brief.md)，不要把三份文档一起丢进去。颜色以麦当劳 Feel-Good Design 公开色板为准：金色是主色，红色是点缀，留白要多。

本项目是参赛者独立作品，不是麦当劳官方产品。不绘制金拱门标志，不使用 Ronald 或官方吉祥物，不把 Speedee 字体文件打进仓库。餐品图只用接口返回的商品图。

## 色彩

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Gold | `#FFBC0D` | 主色。地面、主按钮、选中的商品卡 |
| Red | `#DB0007` | 点缀。生命、危险、价格、Boss 提示 |
| White | `#FFFFFF` | 卡片、主文字底 |
| Black | `#000000` | 金色表面上的文字和图标 |
| Charcoal | `#2D2D2D` | 白色表面上的正文 |
| Light Gray | `#F7F7F7` | 卡片内的次级底 |
| Kraft | `#B69A81` | 障碍、桌椅、纸袋。不拿来写字 |

比例：一屏里金色和白色占大部分，红色只出现在生命、价格和少量强调上。不要整屏铺红，也不要做成深色地牢。

数字界面里允许的文字搭配：

| 底 | 字 | 结论 |
| --- | --- | --- |
| 白 | 炭黑、红 | 正文和价格 |
| 红 | 白 | 短标签，例如「Boss」 |
| 金 | 黑 | 按钮和标题 |
| 金 | 红或白 | 不用 |
| 白 | 金 | 不用。金色在白底上不够清楚 |
| 红 | 金 | 不用 |

生命低、护盾、治疗不要另找一套荧光色。治疗用金色光斑，护盾用白色描边，受伤闪红色。

## 字形

品牌字体是 Speedee，需要授权，仓库里不嵌入字体文件。

拉丁字母和数字用 [Fredoka](https://fonts.google.com/specimen/Fredoka)（圆角、偏宽、可免费使用）。中文用 [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)。以后如果自行取得 Speedee 授权，只替换拉丁字体这一项。

| 角色 | 字体 | 字号 | 字重 |
| --- | --- | --- | --- |
| 关卡标题 | Fredoka | 40px | 700 |
| 商品名 | Noto Sans SC | 20px | 700 |
| 伤害和价格数字 | Fredoka | 28px | 700 |
| 说明 | Noto Sans SC | 16px | 400 |
| 禁用 | — | 小于 14px 的正文 | — |

标题短。一行放得下商品名；放不下就换到两行，不缩小到 14px 以下。行高 1.4。

## 形状

圆角矩形，不要尖角和像素块。

| 元素 | 圆角 |
| --- | --- |
| 商品卡、技能卡 | 24px |
| 按钮 | 999px |
| 生命条 | 999px |
| 障碍 | 12px |
| 角色和怪物 | 圆形或胶囊形，炭黑描边 4px |

描边用炭黑，不用红色描边铺满全身。阴影只保留一层，颜色为金色的 20% 透明，模糊 16px。不要拟物金属、木纹和高光塑料。

## 画面分区

逻辑分辨率仍是 960×540。

**地面。** 场景 1 是浅金 `#FFE7A3`，网格线用 Gold。场景 2 是 Light Gray，网格线用 Kraft。两景都保持明亮。

**障碍。** Kraft 填充，炭黑描边。实体和掩体形状相同，掩体加上 2px 白色内描边，让玩家看得出子弹过不去、人过得去。

**玩家。** 白底圆，炭黑描边，头顶一小节红色圆弧，表示朝向。圆心里贴最近获得的那件商品图。不受伤时不闪红。

**怪物。** 游走怪是红色圆。定点怪是圆角方块，同样红色，但不动，并且顶上有一根短的黑色线，表示它在瞄准。精英把尺寸放大 1.3 倍，描边改成 Gold。Boss 是红色胶囊，尺寸更大，仍用同一套描边，不另画写实生物。

**子弹。** 没带薯条时，普攻仍是细的红色短条。带了对应技能后，法球、汽水、驻留、冰环和分裂出去的小球改贴那件商品的官方图。怪物子弹仍是炭黑短条。环绕球是金色圆，里面贴巨无霸。命中时爆开少量金色粒子。

**掉落。** 四种形状，不靠长句：

| 掉落 | 形状 |
| --- | --- |
| 金币 | 金色圆币，中间黑字数字 |
| 治疗 | 白圆，中间红十字 |
| 护盾 | 白方块，炭黑外框，金色内框 |
| 技能 | 白圆里放对应商品图，炭黑描边 |

**商品卡。** 白卡，圆角 24px。法球用红边和红顶栏、白字；法术用金边和金顶栏、黑字；肉盾用炭黑边和炭黑顶栏、白字。顶栏只写流派，商品名在图下面，互不重叠。按下时边变粗，不改成另一种颜色。

**界面。** 生命是白槽里的红条，黑字。金币是黑字。商店和选分支时压一层 40% 炭黑。菜单价用白底红字。金底只配黑字，红底只配白字。按钮和技能格至少 44×48 像素，按下变深，不靠悬停才看得出能点。轮盘是半透明金环加炭黑钮，只出现在触屏上。横竖屏怎么摆，见 [game-plan.md](./game-plan.md) 的「操作和适配」。

## 动效

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| 商店和技能卡弹出 | 220ms | 先放大到 1.04 再回到 1 |
| 换场景 | 400ms | 金色擦除，从左到右 |
| 受击 | 80ms | 画面轻震，幅度 4px |
| 获得技能 | 500ms | 角色周围一圈金色粒子 |

系统开启「减少动态效果」时：不要震动，不要循环缩放，换场景改为直接切换，粒子数量降为 0。商店和技能卡仍立即出现。

## 实现时替换现有画面

当前启动场景是深棕底和金色辉光，这是调试画面，不符合本文件。接入战斗时改成浅金地面、白卡片和红色点缀。辉光只留在玩家子弹和升级瞬间，不把整屏做成夜店灯光。
